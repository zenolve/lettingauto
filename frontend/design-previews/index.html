What they cost you on the way in

Dimension A · Editorial B · Modern SaaS C · Brutalist Pro
Information density Low — long-form feel Medium High — dense tables
Brand fit (prime-Kensington lettings) ★★★★★ ★★★ ★★★★
Agent speed (daily ops) ★★★ ★★★★★ ★★★★
Implementation cost from today's frontend Low — recolour + font swap Medium — dark mode + glass utilities Low/medium — type swap + rule weights
Tailwind extras needed Custom font family backdrop-blur, dark variants Mono font, sharper borders
Print / PDF feel Excellent (already paper-like) Needs light export shell Excellent

Recommendation: A or C suits the brand better. A is the safer / more obviously premium choice; C is the more distinctive option. B is the right call if the priority is operator speed and the audience is the agent rather than the landlord. Mix-and-match is also fine — e.g. A's typography on B's hero-stat layout.
